Masterclass Knowledge

Foundational Architecture & Principles

Everything you need to know about the science of language models and prompt design.

01

Seq2Seq Bottlenecks

Early RNN and LSTM translation architectures attempted to compress full paragraphs into a single static encoder vector. This bottleneck lost crucial details, names, and numbers in long sequences.

02

The Transformer Revolution

Introduced in 2017 ("Attention Is All You Need"), Transformers abandoned recurrence completely. Parallelized self-attention allows tokens across the entire prompt to directly reference each other.

03

GPT Autoregressive Loop

Generative Pre-trained Transformers predict text token by token. The prompt acts as the initial condition, narrowing down probability distributions to produce targeted answers.

Core Glossary

Autoregressive Generation

Models predict text token by token, appending each output back into the input sequence for the next prediction step.

Few-Shot Prompting

Providing one or more concrete input/output examples within the prompt to ground model behavior.

Hallucination

When an LLM outputs syntactically plausible but factually incorrect statements due to unconstrained probability outputs.
